## 화면 결정 사항

* 탭 순서: 재핑 타임라인 / 경쟁사 홈쇼핑 편성표 / NS 기준 비교 / 상품·가격 검색
* 첫 화면: 컴퓨터는 재핑 타임라인, 폰은 NS 기준 비교.
* 재핑 타임라인 순서 전환:
   * 지상파·종편·케이블 순
   * 지니TV 채널번호 0~24 순: 홈쇼핑 칸 포함. 2026-09-02 채널표 기준이라 번호가 바뀌면 직접 수정해야 함.
* 가격: 방송 판매가 기준. 홈쇼핑모아 쿠폰과 카드할인은 가격에 반영하지 않고, 카드할인은 상세에 참고로만 표시.
* 분류: 홈쇼핑모아 카테고리는 틀린 경우가 있어 쓰지 않음. 동일 상품군 알림·강조도 없음. 겹치는지는 직접 보고 판단.
* "이 방송 시간에 함께 판매": 홈쇼핑사가 같은 방송 시간에 등록한 상품.
   * 본상품 구성이 아닌 다른 상품도 섞여 있음.
   * 다른 시간에 방송할 상품은 상세 화면의 접힌 칸에 따로 표시.
* 날짜 선택: 그제~+7일 버튼, ‹ › 하루씩 이동, 달력으로 지난 날짜 찾기.
