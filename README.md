## 화면 구성

| 탭 | 내용 |
|---|---|
| 재핑 타임라인 | NS홈쇼핑과 일반 TV 채널(지상파·종편·케이블·뉴스)을 시간대별로 나란히 보여줘요. 왼쪽 위 버튼으로 **지상파·종편·케이블 순** 또는 **지니TV 채널번호 순(0~24번, 홈쇼핑 채널 포함)**으로 바꿀 수 있어요. |
| 경쟁사 홈쇼핑 편성표 | 홈쇼핑 7사 편성을 시간대별로 보여줘요. 방송을 누르면 가격과 같이 판매하는 상품이 나와요. |
| NS 기준 비교 | NS 방송 한 건마다 같은 시간에 경쟁사가 무엇을 팔았는지 한 줄로 보여줘요. 휴대폰에서 보기 좋아요. |
| 상품·가격 검색 | 상품명·브랜드로 검색하고, 카드나 표로 가격을 비교해요. |

- 위쪽의 **TV홈쇼핑 / 데이터홈쇼핑** 버튼으로 채널 묶음을 바꿀 수 있어요. 데이터홈쇼핑은 NS Shop+ 기준 11개 채널이에요.
- 날짜는 그제부터 일주일 뒤까지 버튼으로 고르고, 지난 날짜는 ‹ › 버튼이나 달력으로 찾아요.
- 처음 열리는 화면은 PC가 재핑 타임라인, 휴대폰이 NS 기준 비교예요.

## 보는 법

- **가격**: 방송 판매가예요. 홈쇼핑모아 쿠폰과 카드할인은 가격에 넣지 않았어요. 카드할인은 상세 화면에 참고로만 적혀 있어요.
- **"공식" 표시**: 홈쇼핑모아에 없는 방송을 홈쇼핑사 공식 편성표에서 채운 거예요. 가격·구성 정보가 적을 수 있어요.
- **"편성 정보 없음"**: 어느 출처에도 편성이 없는 시간이에요.
- **"이 방송 시간에 함께 판매"**: 홈쇼핑사가 같은 방송 시간에 판매로 등록한 상품이에요. 본상품의 다른 구성뿐 아니라 다른 상품도 섞여 있어요.
- 상품 분류(식품·가전 등)는 출처 데이터가 부정확해서 표시하지 않아요. 같은 상품군이 겹치는지는 직접 보고 판단해 주세요.
